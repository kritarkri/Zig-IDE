# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful and harassment-free project community. Be considerate, use constructive language, respect differing viewpoints, and focus criticism on ideas and code rather than people.

Harassment, discrimination, threats, doxxing, and abusive behavior are not acceptable. Project maintainers may remove content or restrict participation when necessary to protect the community.

For conduct concerns, contact the project maintainers through the repository's issue/reporting channels.
