# Contributing

Thanks for considering a contribution!

1. Open an issue describing the bug or proposed feature before large changes.
2. Fork the repository and create a focused branch.
3. Keep changes small and explain user-visible behavior.
4. Run `npm install`, `npm run typecheck`, and `npm run build` before submitting.
5. Include screenshots for UI changes and reproduction steps for bug fixes.
6. Submit a Pull Request. The project maintainer reviews and decides whether it is included in the official repository.

Contributions are licensed under the repository's MIT License when submitted under the normal GitHub contribution flow. Do not submit code you do not have the right to contribute.

The project maintainer controls releases and the official repository. A public repository does not guarantee that every proposed change will be accepted.
